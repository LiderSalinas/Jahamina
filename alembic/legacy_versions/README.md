# Migraciones archivadas

Estas migraciones de 2025 fueron retiradas antes de la versión 1.0 porque
describían un esquema distinto al usado por la aplicación: contraseña con otro
nombre, campos de viaje inexistentes, fechas separadas y otra tabla de
pasajeros.

La base de desarrollo fue verificada sin filas antes del reemplazo. Estos
archivos se conservan solo como referencia histórica y Alembic no los carga.
